调用步骤

右侧会按真实请求顺序推进，方便观察 Browser 到 MCP 的完整链路。

1

填写筛选条件

输入行业、基金名称或六位代码。

2

浏览器发起请求

页面调用 GET /api/funds。

3

Bridge 调用 MCP

HTTP Bridge 通过 STDIO 请求 fund_market_snapshot。

4

渲染行情结果

页面展示市场类型、涨跌幅、来源时间和详情。

场外基金当天净值未发布时，会明确标记“前一交易日”或“待正式净值”，不会伪装成实时价格。
