# 国内公募基金行情 MCP 设计说明

## 目标

将当前只返回问候语的示例 MCP 扩展为国内公募基金查询 MCP，覆盖场内 ETF/LOF 和场外开放式基金。
用户可以输入任意行业关键词，例如 AI、科技、半导体、医疗、新能源、消费、军工或红利，获取
当天可用的基金行情和基金基本状态。

该工具用于信息查询和技术演示，不构成投资建议。所有结果必须展示数据日期、更新时间、数据类型
和来源，区分正式净值、实时价格与盘中估值。

## 视觉方向

页面改造成“基金行情扫描台”，采用克制的金融数据工作台风格：

- 顶部标题为“国内公募基金行情扫描台”，副标题说明支持场内与场外基金。
- 顶部控制区包含行业关键词输入、市场范围切换、排序方式和查询按钮。
- 主区域左侧是基金行情列表，重点展示代码、名称、场内/场外、涨跌幅、净值/价格和更新时间。
- 主区域右侧是选中基金详情，展示当前行情、数据质量提示和最新行业配置。
- 使用青绿色表示上涨/正常连接，珊瑚色表示下跌/警示，黄色表示“估值”或“待确认”状态。
- 不使用营销式大卡片，不使用装饰性渐变；优先保证表格扫描、状态辨识和移动端可读性。

## 数据源和边界

首版采用 Python AKShare 适配器，由 Node MCP Server 通过子进程调用。AKShare 文档提供：

- `fund_etf_spot_em`：场内 ETF 实时行情，包括最新价、IOPV 实时估值、折价率、涨跌幅、成交量、
  成交额、数据日期和更新时间。
- `fund_open_fund_daily_em`：场外开放式基金每日净值和日增长率；该数据在交易日 16:00-23:00
  更新当天最新净值。
- `fund_portfolio_industry_allocation_em`：指定基金的行业配置和报告截止时间。

数据源文档：

- https://akshare.akfamily.xyz/data/fund/fund_public.html
- https://akshare.akfamily.xyz/data_tips.html

“当天基金状况”定义如下：

- 场内基金在交易时段返回实时价格和实时估值；收盘后保留收盘行情和更新时间。
- 场外基金在官方净值发布前返回上一交易日正式净值，并标记 `officialNavAvailable: false`；
  官方净值发布后才标记为当天正式净值。
- 行业配置属于季度/报告期数据，不冒充当天行情，必须带 `reportDate`。

## MCP 工具

### `fund_market_snapshot`

根据任意关键词和市场范围返回基金列表。

```json
{
  "keyword": "半导体",
  "market": "all",
  "sort": "change_desc",
  "limit": 20
}
```

参数：

- `keyword`：可选，任意行业、主题、基金名称或代码关键词；为空表示全部。
- `market`：`all`、`on_exchange`、`off_exchange`，默认 `all`。
- `sort`：`change_desc`、`change_asc`、`name`，默认 `change_desc`。
- `limit`：1-100，默认 20。

返回统一字段：

```json
{
  "dataDate": "2026-07-11",
  "updatedAt": "2026-07-11T15:05:00+08:00",
  "isTradingDay": true,
  "items": [
    {
      "code": "588200",
      "name": "示例芯片ETF",
      "market": "on_exchange",
      "price": 1.023,
      "nav": null,
      "estimate": 1.021,
      "changePercent": 2.31,
      "volume": 123456,
      "turnover": 9876543,
      "officialNavAvailable": false,
      "source": "东方财富"
    }
  ]
}
```

### `fund_detail`

根据基金代码返回单只基金详情。

```json
{
  "code": "000001",
  "includeIndustry": true
}
```

详情包含基金基本信息、当前行情、净值状态、申购赎回状态和最近报告期行业配置。行业配置为空时
返回空数组和原因，不让单只基金数据失败阻断整个行情查询。

## 分类匹配

首版采用可解释的多字段匹配：

1. 先匹配基金代码和基金名称。
2. 再匹配基金类型、指数名称和可获得的主题字段。
3. 对单只基金详情补充行业配置匹配，但行业配置是报告期数据。
4. 返回 `matchedBy` 字段，说明是名称、代码、类型还是行业配置命中。

不把行业列表硬编码成只有 AI、科技、半导体、医疗；任意中文关键词都可以查询。后续可以增加
独立行业词典，但不改变 MCP 工具接口。

## 错误处理

- 参数错误返回明确的中文错误，不请求外部数据。
- 数据源超时或不可用返回 MCP 工具错误，并说明是行情源暂时不可用。
- 某一数据源失败时，不能把旧数据伪装成当天数据；必须带数据日期和状态。
- 没有匹配基金时返回空列表、查询关键词和提示，不返回虚构基金。
- 网络请求设置超时，避免 MCP 会话永久等待。

## 页面交互

- 初始状态展示可查询、可选市场范围和数据说明。
- 查询过程中显示阶段进度：准备数据源、获取场内行情、获取场外净值、整理匹配结果。
- 查询完成后列表默认按涨跌幅排序，点击列表项更新右侧详情，不重新请求列表。
- “重置”恢复空关键词、全部市场和初始结果。
- 页面明确显示“实时价格”“IOPV 估值”“正式净值”“报告期行业配置”四种标签。

## 测试

- 单元测试覆盖参数校验、市场映射、关键词匹配和字段归一化。
- 适配器测试使用固定数据样本，不依赖实时网络。
- MCP 测试验证两个工具的名称、参数和统一返回结构。
- Web 测试验证查询接口、重置状态、加载阶段和数据状态标签。
- 最终验证使用真实数据源做一次查询，但不把实时结果写入测试快照。
